# Changelog

All notable public changes are documented here. Until the first tagged release, entries describe the default branch and are not release guarantees.

## Unreleased

### Added

- Public security policy and responsible-disclosure process.
- Threat model and product-capability status.

### Changed

- Product positioning now distinguishes implemented execution components from environment-dependent and experimental capabilities.
